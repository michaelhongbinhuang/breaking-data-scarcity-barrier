## Important Notes

This folder contains the .csv file of currency exchange rates. The exchange.csv file includes eight columns: date and the daily exchange rates of eight foreign countries including Australia, British, Canada, Switzerland, China, Japan, New Zealand, and Singapore. The data is sourced from the [Exchange Data](https://www.kaggle.com/datasets/giochelavaipiatti/time-series-forecasts-popular-benchmark-datasets?select=exchange_rate.csv).
